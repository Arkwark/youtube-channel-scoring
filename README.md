Пет-проект по data-аналитике: разработка прозрачной скоринговой модели для оценки YouTube-каналов с целью повышения эффективности медиабаинга.

## 📌 Бизнес-контекст
При планировании рекламных кампаний на YouTube медиабайеры часто опираются на размер аудитории (количество подписчиков). Однако большие каналы не всегда гарантируют высокую вовлеченность (ER) и предсказуемый охват. Бюджет может быть потрачен на каналы с накрученной, пассивной или "спящей" аудиторией.

**Цель:** Создать инструмент (рейтинг), который оценивает каналы не только по охвату, но и по качеству аудитории, стабильности контента и реальной вовлеченности, чтобы минимизировать риски неэффективных закупок.

## 📊 Данные
Анализ построен на базе спарсенных данных (снапшот от 15.10.2026):
* **40 каналов** (метаданные: подписчики, суммарные просмотры).
* **4 217 видео** (после очистки и исключения Shorts для анализа осталось **2 337** длинных видео).
* Подробное описание датасетов находится в [`data/README.md`](data/README.md).

## ⚙️ Методология
1. **Очистка данных:** Исключение `Shorts` (они искажают классический ER из-за разной механики потребления: медианный ER Shorts — 1.83%, Long Video — 3.32%).
2. **Разведочный анализ (EDA):** Оценка распределений (тяжелые хвосты), проверка мультиколлинеарности, визуализация связи размера канала и ER.
3. **Проверка гипотез:**
   * **H1:** Влияет ли размер канала на ER? (Spearman, Kruskal-Wallis).
   * **H2:** Влияет ли длительность видео на ER? (Регрессия OLS с Fixed Effects по каналу и Cluster-robust SE).
4. **Скоринг каналов:** Построение рейтинга на основе 4 метрик (ER, подписчики, просмотры/день, стабильность). 
5. **BCG-матрица:** Квадрантный анализ (Охват × Качество) для визуализации стратегии закупки.

## 📈 Ключевые результаты
* **Гипотеза №1 не подтверждена:** Размер канала не является строгим предиктором ER (Spearman ρ = -0.11, p = 0.49; Kruskal-Wallis p = 0.59). Большие каналы не гарантируют высокую вовлеченность.
* **Гипотеза №2 не подтверждена:** Эффект длительности видео статистически не значим (p ≈ 0.11, 95% ДИ включает 0). Длительность не является позитивным предиктором ER.
* **Скоринговая модель:** Выявляет «Скрытые жемчужины» (высокий ER, низкий охват) и «Звезды» (максимальный охват, стабильный ER), позволяя распределять бюджет (например, 55% в жемчужины, 35% в звезды, 10% в темные лошадки).
