# Описание данных

В этой папке находятся исходные данные, выгруженные из YouTube API (или спарсенные). Данные представляют собой срез (снапшот) на **2026-10-15**.

## 📄 `channels_data.csv`
Содержит метаданные о каналах.
* **Количество строк:** 40
* **Количество столбцов:** 7

**Структура:**
* `channel_id` — Уникальный идентификатор канала (строка).
* `channel_title` — Название канала (строка).
* `subscribers` — Количество подписчиков на момент сбора (integer).
* `total_views` — Суммарное количество просмотров всех видео на канале (integer).
* `video_count` — Общее количество видео на канале (integer).
* `uploads_playlist_id` — ID плейлиста с загрузками (строка).
* `scraped_date` — Дата сбора данных (datetime).

## 📄 `videos_data.csv`
Содержит детальную информацию о последних загруженных видео с каналов.
* **Количество строк:** 4 217
* **Количество столбцов:** 14

**Структура:**
* `channel_id` — Идентификатор канала (внешний ключ для связи с `channels_data.csv`).
* `channel_title` — Название канала.
* `video_id` — Уникальный идентификатор видео.
* `title` — Название видео.
* `description` — Описание (может содержать пустые значения).
* `published_at` — Дата и время публикации видео.
* `views` — Количество просмотров.
* `likes` — Количество лайков.
* `comments` — Количество комментариев.
* `duration_iso` — Длительность в формате ISO 8601 (например, PT15M33S).
* `tags` — Теги видео (через запятую).
* `duration_sec` — Длительность видео в секундах (integer).
* `video_type` — Тип видео: `Shorts` (если длительность <= 60 сек) или `Long Video`.
* `scraped_date` — Дата сбора данных.

**Важное примечание по данным:**
В ноутбуке при анализе из `videos_data.csv` **исключаются все видео типа `Shorts`** (остается 2 337 длинных видео). Это сделано намеренно, так как механика потребления, лайков и алгоритмических рекомендаций у Shorts отличается от длинных видео и сильно искажает классический Engagement Rate.
